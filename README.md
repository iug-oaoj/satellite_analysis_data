# satellite_analysis_data
Este projeto é um trabalho acadêmico. A ideia é: "Um satélite monitora diferentes regiões do Brasil e detecta áreas de desmatamento e incêndios florestais. Os dados são registrados para cada evento. Isso permite a análise de padrões, a identificação de regiões críticas e o apoio a decisões ambientais e estratégicas."

Sistema em Python para simular o processamento de dados de monitoramento ambiental por satélites. Registra eventos como desmatamento e queimadas, analisa os dados e gera um relatório estratégico.
- Cadastro de múltiplos eventos ambientais detectados por satélite
- Validação de entradas (intensidade entre 1–10, área maior que zero)
- Análise automática dos dados:
  - Área total afetada
  - Média de intensidade
  - Região com mais ocorrências
  - Densidade média de ocorrências
  - Evento mais crítico
